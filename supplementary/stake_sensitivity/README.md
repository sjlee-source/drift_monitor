# Betting-gain sensitivity

Run `python supplementary/stake_sensitivity/run_sensitivity.py` from the submission/repository root. Requires NumPy and SciPy. The runner uses one CPU process and no GPU. It recreates calibration (5000), validation (3000) and evaluation (2000) streams using the recorded seed rule, and checks gain 4 against archived alarm arrays. It writes results and checks into this directory. The two simultaneous families each contain 18 comparisons. This is a representative slice (prevalence .10, delay 500, tau 10000, q .10/.20/.50, risks .12/.20), not a replacement for the full operating map. Gains 2/4/8 have separate calibrated thresholds and share streams within each role and condition. All gains are reported; no primary coefficient is selected from this analysis.
